# 🔐 Indovina la Password

Gioco sviluppato in **TypeScript**. L'obiettivo è indovinare una password segreta di 5 cifre generata casualmente, utilizzando gli indizi visivi forniti dal cambiamento di colore dei pallini.

## 🚀 Funzionalità

* **Generazione Casuale**: Ogni sessione di gioco genera una password nuova e imprevedibile.
* **Feedback in Tempo Reale**: I pallini cambiano colore istantaneamente mentre digiti.
* **Logica degli Indizi**:
    * 🟩 **Verde**: La cifra è corretta e si trova nella posizione giusta.
    * 🟨 **Arancione**: La cifra è presente nella password, ma in una posizione diversa.
    * 🟥 **Rosso**: La cifra non è presente nella combinazione.
* **Design Responsive**: Interfaccia ottimizzata per PC, tablet e smartphone, con layout fluido e centrato.
* **Feedback Visivo**: Icone animate per indicare la vittoria (lucchetto aperto) o il tentativo errato.

## 🛠️ Tecnologie Utilizzate

* **HTML5 / CSS3**
* **TypeScript**
* **Vite**

## 📦 Installazione e Avvio

Se vuoi avviare il progetto localmente, segui questi passaggi:

1.  **Clona la repository**:
    ```bash
    git clone https://github.com/tuo-username/indovina-la-password.git
    ```
2.  **Entra nella cartella del progetto**:
    ```bash
    cd indovina-la-password
    ```
3.  **Installa le dipendenze**:
    ```bash
    npm install
    ```
4.  **Avvia il server di sviluppo**:
    ```bash
    npm run dev
    ```
